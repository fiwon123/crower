# Emoji catalogue

`emoji.json` is the `db/emoji.json` file from
[gemoji](https://github.com/github/gemoji), fetched from `master` on
2026-11-06. gemoji is MIT licensed; the text is in `LICENSE` here and in the
repository's `NOTICE`, which every release archive carries.

The picker reads the dataset's own glyph, name, aliases, tags and category. To
update it, replace `emoji.json` with a newer copy; no code change is needed.
