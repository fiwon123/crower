# ♻️ `restore`

**Bring back a command you deleted.**

```bash
crower restore <command>
```

## 💡 Examples

```bash
crower list -i          # find the entry and its snapshot
crower restore deploy   # bring that command back
```

`restore` is for a specific name; [`revert`](revert) is for stepping the whole
history backwards.
